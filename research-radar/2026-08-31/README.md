## 本轮结论

最值得投入的不是单独追求“更漂亮的月面重建”，而是把重建、物理参数、决策风险和在线更新闭成环。当前证据最强的五个桥接点是：

1. 行星域适配的多模态视觉几何基础模型；
2. 同时表达几何、辐射外观和轮壤参数的可更新地图；
3. 将视点选择从画质最大化改为安全、能耗与科学价值联合优化；
4. 用 mission/analogue 数据持续校准 real-to-sim-to-real 数字孪生；
5. 面向长航程与低算力的压缩、分块、带安全证书的在线建图。
