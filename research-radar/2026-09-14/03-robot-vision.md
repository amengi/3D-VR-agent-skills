# 方向三：机器人视觉与具身视觉

本方向只收视觉表示、感知、建图、理解或视觉预测是核心贡献、机器人提供闭环任务验证的论文；纯机械、本体、材料、执行器、纯控制、纯动力学辨识和无视觉机制的一般强化学习未纳入。

## 1. Functional-SLAM

- **关键机制**：不是把功能标签贴到重建后地图，而是让功能节点和边持续参与状态维护，并用拓扑提供回环候选。
- **最值得复现**：功能边的 commit threshold、错误边撤销、无纹理场景回环收益和真实在线成本应同时报告。
- **证据边界**：摘要没有证明开放词汇泛化、动态物体处理或大规模长期地图稳定性。

## 2. FARM（本周首读）

- **WHY/HOW/WHAT**：如果预测式表征已经编码动作后果，轻量读出或许能在不重训策略/世界模型的情况下发现失败。论文的价值是把“内部状态是否含风险信号”变成可测问题，而非再造一个大监测模型。
- **首要复现**：跨任务、跨相机、跨机器人、跨世界模型迁移；按遮挡、目标误识别、接触偏差和动作迟滞拆分 AUROC/AUPRC 与提前量。
- **不能据此断言**：同分布高分不等于对未知失败或行星域有效；小参数量也不保证校准和因果解释。

## 3. FocusPool 与 RoboReel

- **共同问题**：机器人视觉需要保留局部动作充分信息，还要在统一的视觉干扰和长时序协议中验证。
- **研究边界**：FocusPool 的提升可能来自额外本体上下文或参数微调，而非池化本身；RoboReel 的 benchmark 排名不能自动推广到导航、月面或不同本体。

## 独立研究点 A：世界模型内部失败信号的跨域可迁移性

- **假设**：将视觉退化、任务阶段和失败类型显式因子化后，冻结预测状态上的小读出器能跨任务迁移，并比端到端成功预测更早预警。
- **相对已有工作的变化**：从 FARM 的单主干读出推进到跨主干/跨域校准，并要求“哪里坏、提前多久”而不只给二分类。
- **最小验证**：两个公开视觉世界模型、LIBERO/RoboCasa 各 5 个任务；注入遮挡、曝光、模糊、时延、目标替换，最后验证一组真实 rollout。
- **指标**：AUROC/AUPRC、ECE/Brier、平均预警提前量、未知失效召回、跨域性能降幅、延迟。
- **关键基线**：RGB 监测器、action-history 监测器、FARM 式单读出、重训世界模型、随机/能量分数。
- **消融**：无阶段标签；无失败类型；不同预测层；线性/MLP；冻结/微调；单帧/时序。
- **证伪条件**：读出不能跨任务优于外部监测器，或风险分数只学习任务进度而非失败。
- **失败模式与风险**：世界模型共同盲点不留下内部信号；数据泄漏；罕见失败样本不足。风险中高。

## 独立研究点 B：可撤销、任务条件化的功能地图

- **假设**：将 Functional-SLAM 的功能边维护为任务条件化后验并允许撤销，比一次提交的静态图更能支持新任务与遮挡恢复。
- **相对已有工作的变化**：把“功能关系”从单一稳定事实拆成观测证据、任务条件和可供性状态；不依赖机械/控制创新。
- **最小验证**：室内 RGB-D 序列构造重复外观、功能相似对象、遮挡重现和任务切换；用移动操作的找物/交互成功作闭环复核。
- **指标**：功能边 precision/recall、错误信念存活时间、loop ATE、任务成功率、查询延迟、地图内存。
- **关键基线**：几何 SLAM、语义 scene graph、Functional-SLAM、VOIM + 后处理功能分类、无撤销版本。
- **消融**：无任务条件；无多帧 commit；无撤销；无功能回环；固定/自适应遗忘。
- **证伪条件**：任务条件和撤销不改善图准确率或闭环成功，且仅增加复杂度。
- **失败模式与风险**：地图漂移被误作功能变化；任务文本歧义；功能真值昂贵。风险中等。

## 独立研究点 C：局部视觉动作充分性压力测试

- **假设**：在相同编码器和训练预算下，任务条件局部聚合主要改善小目标、低容差和视觉干扰场景，而非所有任务平均提升。
- **相对已有工作的变化**：用 RoboReel 的统一测试轴审计 FocusPool 机制，区分视觉聚合收益与额外本体输入/参数更新收益。
- **最小验证**：10 个 RoboReel 任务子集，固定编码器与动作头，比较 global pooling、crop、FocusPool 和 object token。
- **指标**：成功率、长时序阶段完成率、干扰鲁棒性、样本效率、注意力定位、计算量。
- **关键基线**：平均/最大池化、显式 crop、FocusPool、参数量匹配 adapter、oracle object crop。
- **消融**：无本体上下文；随机上下文；不同中间层；冻结全部编码器；等训练参数。
- **证伪条件**：参数量匹配 adapter 达到相同收益，或注意区域与因果任务线索无关。
- **失败模式与风险**：注意图不可解释；benchmark 泄漏；局部聚合遗漏全局空间关系。风险中等。
